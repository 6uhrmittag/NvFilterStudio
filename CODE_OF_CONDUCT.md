# Code of Conduct

## The short version

Be decent. This is a small tool for keeping game filters safe; nothing here is
worth being unpleasant to a stranger over.

## What is expected

- Assume good faith. Most confusion here comes from an undocumented binary
  format, not from anyone being careless.
- Say what you observed. "Slot 3 came back empty after I applied" helps; "it's
  broken" does not.
- Accept "not proven" as an answer. `docs/FORMAT.md` deliberately separates what
  is verified from what is assumed, and pretending otherwise would eventually
  cost someone their profile.
- Beginners are welcome. Mapping a filter's sliders needs no code at all and is
  the single most useful contribution.

## What is not

Harassment, personal attacks, and demeaning or discriminatory comments,
including about someone's setup, skill or language. Sexualised language or
imagery. Publishing anyone's private information.

Note that people here run NVIDIA Apps in many languages, and the app's own
labels reflect that — do not mock someone for filing an issue in imperfect
English.

## Reporting

Raise it with the maintainer through
[a private security advisory](https://github.com/6uhrmittag/NvFilterStudio/security/advisories/new),
which is the available private channel, or in a public issue if you would rather
it were open.

Reports will be handled in confidence. The maintainer may edit, hide or delete
comments, and block accounts, for behaviour that breaches this document.

## Scope

Applies in this repository — issues, pull requests, discussions, commit
messages — and to anyone representing the project elsewhere.
